# Сайт усадьбы «На Вильчанке»

Адаптивный визуальный макет на React и Vite. Главная страница содержит все основные разделы, а форма бронирования доступна по маршруту `/booking`.

## Запуск

Требуется Node.js 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

Сборка production-версии:

```bash
pnpm build
pnpm preview
```

## Где менять данные

Весь основной контент собран в `src/data/siteData.js`:

- `brand` — название и короткое описание;
- `contacts` — телефон, адрес, мессенджер, соцсети и ссылка на маршрут;
- `hero` и `about` — контент первого экрана и блока об усадьбе;
- `gallery` — список фотографий и подписи;
- `prices` — услуги и цены;
- `menu` — категории и блюда;
- `reviews` — отзывы;
- `booking` — варианты в форме бронирования.

Базовые SEO-заголовки и метатеги для превью находятся в `index.html`; после утверждения названия их также нужно обновить там.

Цвета, типографика и размеры задаются CSS-переменными в начале `src/styles.css`.

Изображения находятся в `public/images`. Чтобы заменить фотографию без правок кода, сохраните новый файл под тем же именем.

## Важно

Форма на первом этапе не подключена к серверу: после отправки она показывает демонстрационное сообщение об успехе. Для реального сайта потребуется API или сервис приёма заявок.

Маршрут `/booking` работает как часть SPA. Для Netlify и Vercel в проект уже добавлены правила перенаправления на `index.html`. На другом статическом хостинге потребуется аналогичная SPA fallback-настройка.

## Временные фотографии

Контент собран по официальному Instagram усадьбы и карточке Яндекс Карт. Реальные фотографии взяты из предоставленной владельцем карточки Яндекс Карт; ссылки на источники сохранены в массиве `sources` файла `src/data/siteData.js`.
